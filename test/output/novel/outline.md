# 大纲

## 第 1 章：巷口的风

**核心事件**：七岁夏末，苏念一家搬进临江巷，与林家成为邻居。苏念的风筝挂上老槐树，林昭爬树取下来还给她，两人初次相识，奠定'他护她'的底色。

**钩子**：大人们逗苏念'长大要嫁给谁'，苏念指着林昭喊'嫁给小昭'，满院子哄笑，林昭红着脸跑回家。

**场景**：
1. 搬家车停在巷口，苏念对新环境既好奇又紧张
2. 风筝挂上槐树，林昭爬树取风筝，两人第一次说话
3. 两家大人在院里寒暄，林母叶兰与苏母热络得像老姐妹
4. 大人逗乐问嫁娶，苏念童言'嫁给小昭'，林昭落荒而逃

## 第 2 章：同桌

**核心事件**：小学同班，两人被分到同桌。分半块橡皮、共享早点，林昭替苏念背了摔碎粉笔盒的黑锅。

**钩子**：苏念发现自己的涂鸦画被林昭贴在铅笔盒盖内侧，问他，他只说'好看'。

**场景**：
1. 开学分桌，苏念看见同桌是林昭，松了口气
2. 分半块橡皮的约定，成为往后多年的习惯
3. 林昭替苏念背黑锅，被老师罚站一节课
4. 苏念发现铅笔盒盖里的涂鸦，两人别扭又高兴

## 第 3 章：绿豆汤

**核心事件**：炎夏，两家人常在巷口绿豆汤店消暑。苏念中暑，林昭背她回家照顾，两家大人开'娃娃亲'玩笑，苏念第一次觉得难为情。

**钩子**：林昭把碗里最大一块冰拨给苏念：'你怕热。'苏念第一次注意到他的细心，脸发烫。

**场景**：
1. 绿豆汤店两家消夏，孩子们抢冰
2. 苏念中暑头晕，林昭背她回家
3. 叶兰阿姨逗趣说'娃娃亲'，苏念难为情
4. 冰块细节与那句'你怕热'

## 第 4 章：分岔的路口

**核心事件**：小学毕业，划片升初中，两人被分到不同班级。苏念第一次尝到'不在同一班'的失落。

**钩子**：林昭把写着'有事来二班找我'的纸条塞进她书包，没让她看见。

**场景**：
1. 毕业典礼与合影
2. 分班结果公布，两人都不自在
3. 开学第一天各自走进不同的教室
4. 苏念在书包里摸到纸条，捏着看了很久

## 第 5 章：青梅竹马

**核心事件**：初一，不同班的疏离让两人都别扭。高年级男生在走廊堵住苏念要联系方式，林昭赶来把她拉走，同学起哄'青梅竹马'。

**钩子**：回家路上苏念在玻璃门里看见自己红了脸，第一次觉得'青梅竹马'这个词烫人。

**场景**：
1. 不同班的日常，两人见面变少
2. 苏念交到新朋友，心里却空落落的
3. 走廊被堵，林昭护她离开
4. '青梅竹马'起哄，两人一路没说话
5. 苏念在家门口玻璃上看见自己发红的脸

## 第 6 章：又同桌

**核心事件**：初二重新分班，两人同班同桌。同学起哄让两人刻意回避，程茵出场，向苏念打探林昭的喜好。

**钩子**：程茵问'你跟他那么熟，他喜欢什么样的女生'，苏念发现自己答不上来，心里发堵。

**场景**：
1. 重新分班，两人同桌回归
2. 同学起哄'两口子'，两人都别扭
3. 苏念刻意冷淡，林昭不明所以
4. 程茵打探喜好，苏念答不上来

## 第 7 章：没有送出去的信

**核心事件**：程茵托苏念转交情书，苏念犹豫一整天后还是递了，林昭看都没看就退回：'我不需要这个。'

**钩子**：放学路上林昭说'你以后别替人送这种东西'，苏念愣住，琢磨不透他这句话是说给程茵，还是说给她。

**场景**：
1. 程茵在走廊拦住苏念托信
2. 苏念攥着信犹豫了一整天
3. 把信递给林昭，他看也没看就退回去
4. 放学路上的那句话与苏念的心事

## 第 8 章：同一把伞

**核心事件**：中考，两人约定考同一所高中。考试日暴雨，林昭等在考点门口把伞塞给苏念，自己淋雨走。

**钩子**：放榜两人都考上重点高中，苏念打电话报喜，听见电话那头的林昭笑：'说了会一起的。'

**场景**：
1. 备考冲刺，两人在巷口路灯下互相抽背
2. 中考两天，考场外的等候
3. 暴雨中塞伞，林昭淋湿的背影
4. 放榜报喜，电话那头的笑

## 第 9 章：隔壁班

**核心事件**：高一，两人同校不同班。林昭有了自己的圈子，苏念感到疏远。运动会上程茵喊'林昭加油'，苏念发现自己在意的是别人喊他名字。

**钩子**：苏念借口接水离开看台，回头时看见林昭越过人群朝她这边看——她不确定他看的是不是她。

**场景**：
1. 高一开学，两人被分到隔壁班
2. 林昭的理科男生圈子，苏念的疏远感
3. 运动会接力赛，程茵的'林昭加油'
4. 看台到操场的错位对视

## 第 10 章：隔着玻璃窗

**核心事件**：高二文理分科，苏念选文科（为摄影铺路），林昭选理科（为建筑打底）。分科后苏念在画室画老巷，林昭路过，两人隔着玻璃窗互相看见，谁都没进去。

**钩子**：那晚林昭在QQ上发来一句：'你画的那条巷子，我每天上学都走。'

**场景**：
1. 分科志愿的各自抉择
2. 苏念在画室画老巷
3. 林昭路过玻璃窗，两人对视又移开
4. QQ上那句没头没尾的话

## 第 11 章：考场门口

**核心事件**：高三，林昭每天在她课桌放一瓶牛奶。高考结束，林昭等在考场门口说'走了，回家'，两人骑车穿过老巷。

**钩子**：车链在巷口断了，林昭蹲下修，苏念站在他身后，第一次冒出'如果以后不是这个人陪我回家怎么办'的念头，把自己吓住。

**场景**：
1. 高三的牛奶与课桌纸条
2. 高考两天考场内外的各自紧张
3. 考场门口那句'走了，回家'
4. 骑车穿巷与断链，苏念被自己的念头吓住

## 第 12 章：江城

**核心事件**：大学，两人都考到省城江城，不同学校（林昭建筑系、苏念新闻系）。周末相聚，林昭带她看正在施工的新街：'以后我要设计这样的楼。'

**钩子**：苏念在工地板房外给林昭拍了一张逆光照，照片里他身后是没盖好的楼——她忽然发现他长大了。

**场景**：
1. 录取通知书与两家人的高兴
2. 各自大学的新生活，周末成为约定
3. 林昭带苏念看施工中的新街
4. 逆光照片与'他长大了'的发现

## 第 13 章：给你盖一间

**核心事件**：大二暑假，林昭去设计院实习，苏念参加摄影采风，第一次整个暑假没怎么见面。苏念把夕阳老屋的照片发给林昭，他回：'等我毕业，给你盖一间这样的。'

**钩子**：这条消息之后两人都沉默了，苏念盯着屏幕看了很久，最后只回了一个'好'字。

**场景**：
1. 各自的暑假与实习、采风
2. 老屋夕阳照片发过去
3. '给你盖一间这样的'
4. 屏幕前长久的沉默与一个'好'字

## 第 14 章：差点说出口

**核心事件**：毕业季，林昭签江城设计院，苏念拿到本地工作室offer，都留在江城。庆祝那晚林昭欲言又止：'苏念，我们是不是……'被同学敬酒打断。

**钩子**：散场后苏念收到林昭的消息'没事，明天再说'，可那个'明天'谁都没再提。

**场景**：
1. 毕业答辩与签约
2. 庆祝饭局上的起哄
3. 林昭那句被掐断的话
4. 出租车上的消息与没人再提的'明天'

## 第 15 章：旧相册

**核心事件**：工作第一年，苏念跟师父何望学艺，林昭在设计院加班。周末例行见面，苏念偶然翻出林昭的旧相册——全是从小到大收集的她的照片。

**钩子**：相册最后一页夹着小学那半块橡皮，苏念问'你留这个干什么'，林昭说'不知道，就是没扔'。苏念把橡皮放回去，没敢再问。

**场景**：
1. 职场日常：何望的毒舌与指点
2. 设计院加班的林昭，例行周末
3. 翻出旧相册，二十年的照片
4. 半块橡皮与'就是没扔'

## 第 16 章：都在催

**核心事件**：27岁，两家人开始明里暗里撮合催婚，同学聚会起哄。苏念开始怀疑：'我们在一起，是因为喜欢，还是因为所有人都觉得我们该在一起？'

**钩子**：苏念对林昭说'我想搬出去住一段时间'，林昭端着碗的手顿了一下，说'好'。

**场景**：
1. 叶兰阿姨安排相亲局试探
2. 苏建国不催婚，只说'你自己想清楚'
3. 同学聚会'什么时候办事'的起哄
4. 饭桌上那句'我想搬出去'与一声'好'

## 第 17 章：上海

**核心事件**：何望介绍苏念去上海知名工作室两年。苏念深思后决定去——既是事业机会，也是想弄明白自己。林昭只回了一个'好'。

**钩子**：送机那天林昭没进航站楼，苏念过安检前回头，看见他站在出发层玻璃门外，手里拎着一袋绿豆汤——他没进来，也没走。

**场景**：
1. 何望的推荐与利弊分析
2. 深夜长谈，谁都没把话说透
3. 订票、辞职、收拾行李
4. 机场送别：玻璃门外的身影与绿豆汤

## 第 18 章：一个人住的房间

**核心事件**：上海，异地第一个月。苏念加班、搬家、独自吃饭，习惯性想给林昭发消息又删掉。

**钩子**：深夜视频接通，两人都没说话，林昭那头传来切菜声——他在做绿豆汤，镜头对着锅：'你不是说这边喝不到吗。'苏念忽然哭了。

**场景**：
1. 上海出租屋与陌生城市
2. 加班到深夜，打了又删的消息
3. 周末独自在江边，想起老巷
4. 视频通话与镜头里的绿豆汤

## 第 19 章：两人份的早餐

**核心事件**：林昭视角。他习惯性买了两份早餐才发现只有自己。他翻出旧相册，去看即将拆迁的老巷，意识到自己从没说过喜欢，因为'她一直都在'让他以为不用说。

**钩子**：林昭请年假订了去上海的票，给苏念发消息：'巷口下个月拆，我想和你回去拍最后一张。'

**场景**：
1. 早餐店前习惯性的'两份'
2. 翻旧相册，一页页都是她
3. 老巷的拆迁公告与槐树下的停留
4. 订票、发消息

## 第 20 章：重新认识

**核心事件**：上海重逢。林昭在工作室楼下等她，带了自己练了很多次的绿豆汤。两人在江边把二十年的话说开：她怕被期待蒙蔽，他怕开口毁掉现状。

**钩子**：林昭掏出那半块橡皮：'苏念，我们重新认识一次。我叫林昭，住在你隔壁，喜欢你已经很多年。'

**场景**：
1. 工作室楼下的等候
2. 一袋绿豆汤与'我练了很多次'
3. 江边长谈：被期待与不敢开口
4. 半块橡皮与重新自我介绍

## 第 21 章：同一条路

**核心事件**：两人回临江。拆迁前苏念拍下老巷最后一张照片，林昭展开他偷偷设计的改造方案——新街里有一条'念巷'，图纸第一页画着当年那条老巷。他求婚，兑现'给你盖一间'。

**钩子**：苏念没接戒指，先掏出手机把镜头对准他：'你再说一遍。'林昭对着镜头又说了一遍求婚的话——她拍下来：'这样你就赖不掉了。'

**场景**：
1. 回临江，拆迁前的老巷
2. 苏念拍最后一张，林昭在旁
3. 展开图纸：念巷与第一页的老巷
4. 求婚与反拍的玩笑

## 第 22 章：婚礼

**核心事件**：婚礼。两家人、程茵、何望、老同学齐聚，老照片slideshow放完二十年的他们。婚后两人走在同一条新街上，林昭牵着她，像小时候牵她回家。

**钩子**：巷口新开的绿豆汤店老板问'两碗？'，林昭说'两碗'，苏念在边上笑——故事结束在他们走进店里。

**场景**：
1. 婚礼准备与接亲
2. 仪式与老照片slideshow
3. 敬酒：程茵的祝福、叶兰阿姨的眼泪、苏建国交托的话
4. 新街散步与新开的绿豆汤店
