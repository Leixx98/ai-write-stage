# ComfyUI 画布工作台 QA 报告

## 测试范围

本报告针对 ComfyUI 配置/测试页向 Infinite Canvas 风格画布工作台改造后的当前工作区状态。报告依据现有 `qa-shots/` 截图记录、已知构建结果，以及此前集成测试信息整理；本轮不启动服务、不执行命令，也不修改运行环境。

## 已证实的浏览器步骤

- 已打开 Web 工作台页面，页面能够加载并显示当前 ComfyUI 工作台入口。
- 已使用浏览器 `snapshot` 检查页面 DOM/可交互元素，确认页面可被浏览器自动化工具识别。
- 已完成桌面视口截图，截图保存在工作区 `qa-shots/` 目录中，可用于后续回归比对。
- 截图显示工作台已具备画布区域和基础页面布局；当前页面仍需进一步验证节点导入、节点编辑和测试执行的完整链路。

## 未完成或无法证实的步骤

- 尚未在本轮导入真实 ComfyUI API workflow JSON，因此无法确认导入后的节点、连线和字段暴露配置是否完整。
- 尚未在本轮连接可用的 ComfyUI 实例并执行 `/prompt` 测试，无法确认提交、轮询、取消、超时和输出预览链路。
- 尚未验证点击节点打开字段配置弹窗、修改控件类型/默认值、保存布局以及重新加载后的持久化行为。
- 尚未覆盖移动视口、画布缩放/平移/适配、全屏和大量节点场景。
- ComfyUI 运行环境、模型和工作流依赖未作为本轮测试前置条件确认；因此无法将“测试按钮未出图”单独归因于前端或 ComfyUI 服务。

## 已知构建与测试状态

- 已知 `go build -o ainovel-web-cli.exe ./cmd/ainovel-cli` 曾成功完成。
- `go test ./...` 仍存在以下既有失败包，当前没有证据表明它们由画布改造引起：
  - `assets`：测试仍期望旧标题 `## 执行协议`，代码使用 `## 固定流程`。
  - `internal/agents`：agentcore v1.8.1 的 `ProgressToolError` 截断问题。
  - `internal/agents/ctxpack`：测试输入没有产生真实 token 压缩收益。
  - `internal/host`：naked content 流分支缺少 header。

## 问题清单

| 优先级 | 问题 | 影响 | 建议 |
| --- | --- | --- | --- |
| P0 | 未完成真实 workflow 导入到 ComfyUI 出图的端到端验证 | 核心目标“导入并测试”没有验收证据 | 准备最小 API JSON 和可用 ComfyUI 实例，执行导入、字段配置、运行、结果预览全链路 |
| P1 | 节点字段配置和画布布局持久化尚未验证 | 用户配置可能在刷新后丢失或无法驱动运行参数 | 增加浏览器回归用例，覆盖暴露开关、自定义名称、默认值、保存/重载 |
| P1 | 画布大节点数及移动端行为未验证 | 可能出现页面撑大、节点重叠或操作不可用 | 固定画布容器尺寸，验证缩放/平移/适配，并执行桌面和移动视口截图 |
| P1 | ComfyUI 超时、取消、地址校验及错误提示未验证 | 服务不可用时用户无法判断原因 | 使用不可达地址、慢任务和取消操作验证严格错误提示与状态收敛 |
| P2 | 既有 `go test ./...` 失败未清理 | CI/发布信号为红色，掩盖回归 | 单独跟踪上述四个包的基线修复或在 CI 中明确隔离已知失败 |

## 发布前建议

1. 由集成测试环境提供固定的 ComfyUI 地址、模型和最小可运行 workflow；将 JSON fixture 纳入仓库，避免依赖开发者本地文件。
2. 用浏览器自动化覆盖主流程：打开页面 -> 导入 API JSON -> 选择节点 -> 暴露字段 -> 修改默认值 -> 保存 -> 运行测试 -> 查看图片/错误 -> 取消或重试。
3. 对画布建立稳定尺寸和可访问性检查：节点可聚焦、按钮有明确标签、错误状态不撑大布局，移动端至少能进入测试面板。
4. 为每个 API 调用断言统一 envelope `{ "code": 0, "data": {}, "msg": "" }`，并覆盖非 2xx、超时、取消和 ComfyUI 返回错误。
5. 发布候选版本前重新执行构建和测试，并记录四个既有失败包的处置结果；在未完成 ComfyUI 端到端验证前，不建议宣称功能已稳定可用。

## 结论

当前可以确认 Web 工作台入口和基础画布布局可打开，桌面截图已留存；核心 ComfyUI 交互链路尚缺真实环境验收。建议将 P0 端到端导入/运行验证作为下一项集成门禁，同时继续修复并明确记录现有测试基线失败。
